Output{ data: LookupOption[] } or a page-specific normalized lookup payload.

Show input / output
InputRead path uses { get_summaryonly: true } or {}. Write path posts a JSON diff or selected fields plus id.

Show input / output

GET / POST / PUT {newHostUrl}/v1/authenticated/cdhaquestions/OROFACIAL_STATUS Profile load/edit, Join create-account flow, Renew bootstrap, upgrade flows Wicket Loads the orofacial question and creates or updates the answer when the member profile changes.
Show input / output
InputGET has no body. POST/PUT sends { question_code, question, answer }, with seqn added for updates.
Output{ data: CdhaQuestion[] } on read and the new API JSON response on write.
GET / POST / PUT / DELETE {newHostUrl}/v1/authenticated/education Profile, Join student education, Renew student education, upgrade-to-grad flow Wicket CRUD for the member education records managed by the profile, join, renew, and upgrade flows.

Output{ success, data: Education[], message? } for reads and writes.

Output{ success, data: AreaOfExpertise, message? }.
